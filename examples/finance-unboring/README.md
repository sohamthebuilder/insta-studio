# Example account: finance.unboring

The first account built with this studio (Instagram and YouTube, India, money explained in 60-second
cartoons). It is here as a worked example of a filled-in account, not as content to reuse.

| File | What it shows |
|---|---|
| `BRAND.md` | A complete brand guide: voice, 8-beat formula, palette, specs, captions, SEBI safety rules |
| `finance-story.SKILL.md`, `finance-social.SKILL.md` | The original niche skills that `reel` and `social` were generalised from |
| `reel-sensex-classroom/` | The approved reference reel: `Film.tsx`, `story.ts`, `audio_cues.json` |
| `pieces/` | Real carousel and story-set piece files (copy one into `studio/src/pieces/` to see how it's built) |
| `brand-sheets/` | Its template sheet, YouTube banner and profile picture |

Its colours, voice and mascot (Mini, a peach bean in a sun hat) are the defaults in `account.json`.
