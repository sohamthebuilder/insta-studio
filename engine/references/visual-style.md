# The look

The look of a reel is picked per account and per reel. It is no longer fixed in this file.

1. Read `account.json` → `styles.default` (and the reel's chosen style, if Gate 1 picked another).
2. Read `styles/ADAPTING.md` first (what every style must keep for this account: 9:16, safe zones,
   ElevenLabs voice, brand subtitles, mascot, hook-first).
3. Then read `styles/<slug>/STYLE.md` for that style.

The original house look (soft flat storybook in SVG) is now `styles/storybook/STYLE.md`.
